# PORTCULLIS

[![CI](https://github.com/Kaushik2210/PORTCULLIS/actions/workflows/ci.yml/badge.svg)](https://github.com/Kaushik2210/PORTCULLIS/actions/workflows/ci.yml)

**A real-time adversarial prompt-injection detection gateway for LLM applications.**
Think WAF, but the payloads are natural language and the protected asset is a model's
instruction hierarchy.

> **Status: Milestone 8 of 11.** The full L0–L5 cascade now exists end to end in the live
> gateway: input-side detection (L0–L4) and egress inspection (L5 — canary tokens, secret/PII
> scanning, exfiltration detection) on every `/v1/chat/completions` call. Run `just demo-m6` for
> the base_url swap, `just demo-m7` for multi-turn conversation escalation, `just demo-m8` for a
> live system-prompt-leak catch. **L3 is a deliberate scope cut** (never had a milestone number —
> see [ADR-0007](docs/adr/0007-gateway-scope-and-mock-upstream.md)). None of L1–L5's rules or
> thresholds are benchmarked against a labelled corpus — the shipped policy thresholds remain
> unmeasured placeholders, L4 has no multi-turn corpus to measure against
> ([l4-report.md](docs/benchmarks/l4-report.md)), and L5's rules are reviewed the same way L1's
> are (true/false-positive test cases, not a corpus measurement —
> [l5-report.md](docs/benchmarks/l5-report.md)). Every metric below is `TBD` and will be
> regenerated by `just eval` (Milestone 9); none has been hand-typed.

## Architecture

A cost-ordered cascade of heterogeneous layers with short-circuit evaluation. Cheap layers run
first; expensive layers only see traffic the cheap ones found ambiguous.

| Layer | Role |
|---|---|
| **L0** | Normalisation and de-obfuscation. Unicode NFKC, zero-width and bidi stripping, confusable folding, layered decoding with a depth cap. Obfuscation depth is scored as signal, not merely removed. |
| **L1** | Signature and heuristic engine. Versioned YAML rules, fully explainable, zero ML. |
| **L2** | Learned multi-label classifier (ONNX, INT8) plus an embedding kNN sidecar for nearest-known-attack matching. |
| **L3** | *Cut.* LLM adjudication in an uncertainty band was in the original architecture but never got a milestone number — dropped as a deliberate scope decision at M6 rather than filling the gap silently. See [ADR-0007](docs/adr/0007-gateway-scope-and-mock-upstream.md). |
| **L4** | Conversation state machine (`NORMAL → PROBING → ESTABLISHING → EXPLOITING`). Cumulative risk with time decay, crescendo detection, role drift, topic-pivot-after-refusal — a policy-verdict modifier, not a fusion input (no multi-turn corpus exists to fit one against). See [ADR-0008](docs/adr/0008-l4-conversation-state-machine.md). |
| **L5** | Egress inspection. Canary tokens (zero-FP by construction — halts the response), secret/PII scanning and markdown-image/tool-call exfiltration detection (redacted in place, not blocked — real false-positive risk). See [ADR-0009](docs/adr/0009-l5-egress-inspection.md). |

Fusion is learned over layer scores, not a hand-tuned `max()`, and the comparison against
`max()` is published either way. Policy is `ALLOW | FLAG | SANITISE | CHALLENGE | BLOCK`, with
shadow mode as a first-class deployment option.

Rationale and rejected alternatives: [ADR-0001](docs/adr/0001-layered-cascade.md).

## What this is not

PORTCULLIS is a **mitigation**, not a **security boundary**. Prompt injection is not a bug with
a patch, and no text classifier resolves it. The threat model states plainly that an adaptive
attacker with white-box access defeats a detector of this class in the general case, and the
eval harness measures exactly that — publishing the attack success rate including where it is
bad.

It also detects **instruction subversion**, not **toxicity**. Those are different problems, and
conflating them produces a detector that flags a security researcher discussing injection while
missing a polite role-reassignment. This project's own documentation is a regression test that
must not be blocked.

Read [`docs/threat-model.md`](docs/threat-model.md) before the code.

### OWASP LLM Top 10 (2025)

Addresses LLM01 (Prompt Injection), LLM02 (Sensitive Information Disclosure), LLM05 (Improper
Output Handling), LLM06 (Excessive Agency), **LLM07 (System Prompt Leakage)**, **LLM08 (Vector
and Embedding Weaknesses)** and LLM10 (Unbounded Consumption). Full mapping with per-layer
attribution is in the [threat model](docs/threat-model.md#6-owasp-llm-top-10-2025-mapping).

## Quickstart

Requires Python 3.13+, [`uv`](https://docs.astral.sh/uv/), [`just`](https://just.systems/) and
Docker.

```bash
git clone https://github.com/Kaushik2210/PORTCULLIS.git && cd PORTCULLIS
just install
just check
```

| Command | What it does |
|---|---|
| `just check` | Lint, `mypy --strict`, and tests — the same gates as CI |
| `just bench` | Re-measure the L2 latency frontier on your machine |
| `just l2 && just m5` | Train/export L2 and fit fusion — produces the checkpoint the demos need |
| `just demo-m6` | The Milestone 6 checkpoint: starts the gateway and mock upstream, shows a swap |
| `just demo-m7` | The Milestone 7 checkpoint: a real multi-turn conversation plus the crescendo algorithm |
| `just demo-m8` | The Milestone 8 checkpoint: a live system-prompt-leak catch plus secret redaction |
| `just up` / `just down` | Redis + Postgres via Docker Compose |
| `just test-model` / `just test-infra` | Tests needing the real checkpoint / a real Redis |
| `just eval` | Regenerate every README metric (Milestone 9) |
